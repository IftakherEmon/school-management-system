# School Management System

A responsive multi-page website for a school, built as a Mid-Term project for the **Web Technologies (CSC 3215)** course at American International University-Bangladesh (AIUB).

## 📖 Overview
This project is a static informational website for a school, allowing visitors to learn about the institution, its teachers, admission process, and contact information. Built using core web technologies — HTML5, CSS3, and JavaScript — with semantic markup and a responsive, mobile-friendly layout.

## ✨ Pages
- **Home (`index.html`)** — Landing page introducing the school
- **About (`about.html`)** — School history, mission, and vision
- **Teachers (`teachers.html`)** — Faculty listing with details
- **Admission (`admission.html`)** — Admission process and requirements
- **Contact (`contact.html`)** — Contact information and inquiry form

## 🛠️ Tech Stack
- HTML5 (semantic elements)
- CSS3 (responsive layout, styling)
- JavaScript (interactivity, form validation)
